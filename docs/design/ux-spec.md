# ZTorrent — UX-спецификация

**Версия:** 1.0 · **Статус:** к реализации · **Платформа:** Windows 11, WPF, .NET 10
**Окно по умолчанию:** 1440 × 900 DIP, минимум 1024 × 640 DIP
**Дизайн-система:** [design-system.md](./design-system.md) — токены, компоненты, motion, доступность.

Документ описывает поведение: экраны, состояния, раскладку, взаимодействия и точные
русские тексты. Все размеры — DIP. ID в квадратных скобках — `AutomationId` и `x:Name`
для XAML; `[..]` в схемах — кнопки и контролы.

---

## 1. Область, модель и термины

### 1.1 Что входит в v1

Библиотека, панель деталей (обзор, файлы, трекеры, пиры), добавление magnet/.torrent,
пауза/возобновление, удаление (с данными и без), приоритеты файлов, лимиты скорости,
DHT/PEX/LSD/шифрование, статистика, настройки, трей, тосты, drag&drop, контекстные меню,
горячие клавиши. Русский язык — единственный в v1 (плюрализация и форматы — `ru-RU`).

### 1.2 Термины

| Термин | Значение |
|---|---|
| Торрент | Запись библиотеки: `InfoHash`, имя, размер, состояние, скорости, прогресс |
| Состояние | `Metadata`, `Queued`, `Downloading`, `Seeding`, `Paused`, `Checking`, `Error`, `Completed` |
| Активный | `Downloading` или `Seeding` с ненулевой скоростью |
| Метаданные | Сведения из `.torrent`; у magnet появляются после обмена с пирами (BEP 9) |
| Метка | Пользовательская категория (Фильмы, Музыка, Игры, Софт, Другое, своя) |
| Bulk-бар | Плавающая панель действий над выделением |

### 1.3 Правила поведения интерфейса

1. Любое действие мгновенно отражается в UI (оптимистично), затем подтверждается
   событием движка. Откат — при ошибке + тост с причиной.
2. Деструктивные действия без подтверждения только в одном случае: «Отменить» в тосте
   доступно 10 секунд. Остальное — диалог.
3. Интерфейс никогда не блокируется: любая операция длиннее 150 ms показывает локальный
   прогресс (спиннер в кнопке, скелетон в списке).
4. Все числа — из одного снимка состояния (`TorrentSnapshot`), обновление ≤ 2 Гц.

## 2. Карта экранов

```
Окно ZTorrent (main window)
├── Библиотека — главный экран
│   ├── Сайдбар: статусы (6) · метки · инструменты · виджет скорости
│   ├── Список торрентов (виртуализированный, 76 px строка)
│   ├── Панель деталей: Обзор · Файлы · Трекеры · Пиры
│   ├── Состояния: loading · empty · no-results · filtered-empty · error · offline · metadata
│   └── Слои: bulk-бар · drag&drop-оверлей · контекстные меню · тосты
├── Статистика — счётчики, график, соединения, диагностика
├── Настройки — 8 секций (Общие … О программе)
├── Модальное окно «Добавить торрент» (ссылка / файл)
├── Диалог «Удалить торрент» (с данными / из списка)
└── Трей — значок, контекстное меню, баллун, восстановление окна
```

Навигация: **Библиотека** ↔ **Статистика** ↔ **Настройки** — левый сайдбар, `Ctrl+1…6`
переключают статусные фильтры библиотеки, `Ctrl+,` — настройки. Модалки и диалоги
открываются поверх любой страницы и возвращают фокус на элемент-источник.

### 3.4 Поведение окна

| Событие | Поведение |
|---|---|
| Запуск | окно по центру рабочей области, размер 1440 × 900, но не больше `WorkArea − 80`; состояние запоминается |
| Второй запуск | активируется существующее окно (single instance), новый экземпляр завершается |
| Закрытие (✕) | если `Сворачивать в трей` включено (по умолчанию **да**) — окно скрывается, движок работает, первый раз показывается баллун; иначе — выход с подтверждением, если есть активные загрузки |
| Свернуть | обычное сворачивание в панель задач; `TaskbarItemInfo.ProgressState=Normal`, `ProgressValue` = средний прогресс активных |
| Развернуть | `Snap Layouts` работают (WindowChrome `CaptionHeight=40`), двойной клик по тайтлбару |
| Перетаскивание из maximized | окно восстанавливается и продолжает движение за курсором (Win11-поведение) |
| Изменение размера | `ResizeBorderThickness=6`, минимум 1024 × 640 |
| DPI-переезд | окно перестраивается без перезапуска; `UseLayoutRounding=True` |
| Потеря фокуса | shimmer и пульсации останавливаются, тосты ставят таймер на паузу |

## 4. Тайтлбар `[TB]`

Высота 40, фон `Bg.Window`, нижняя граница 1 px `Border.Subtle`.

| Элемент | ID | Позиция / размер | Содержимое |
|---|---|---|---|
| Статус сети | `TB.Status` | x=12, y=8, высота 24, радиус 12, padding 8 | точка 6 px + текст 12/16 |
| Глобальные скорости | `TB.Speeds` | сразу за статусом, x ≥ 180 | «↓ 7,8 МБ/с · ↑ 1,2 МБ/с», 12 tabular `Text.Secondary` |
| Кнопки окна | `TB.Min`, `TB.Max`, `TB.Close` | справа, 46 × 40 каждая | глифы `E921`, `E922`/`E923`, `E8BB`, 10 px |

В тайтлбаре **нет** логотипа и названия: бренд живёт в сайдбаре (§5.1), чтобы не
дублировать подпись и не тратить 40 px на повтор.

Состояния `[TB.Status]`:

| Состояние | Точка | Текст | Клик |
|---|---|---|---|
| Подключено | `#4ADE80` | «Подключено · DHT 12 840» | Статистика |
| Подключение | `#FBBF24` | «Подключение…» | Статистика |
| Нет соединения | `#FB7185` | «Нет соединения» | Статистика |
| Пауза (все торренты) | `#94A3B8` | «На паузе» | Статистика |
| Порт закрыт | `#FBBF24` | «Порт закрыт» | Настройки → Сеть |

Правила:
- `[TB.Speeds]` скрыт, если суммарные скорости < 1 КБ/с; значения обновляются 2 раза в
  секунду, без анимации цифр.
- Кнопки окна: hover — фон `#14FFFFFF`; `[TB.Close]` hover — `#C42B1C`, глиф `#FFFFFF`;
  pressed — `#0F000000` поверх.
- Область перетаскивания — весь тайтлбар, кроме `[TB.Status]`, `[TB.Speeds]` и кнопок
  (`WindowChrome.IsHitTestVisibleInChrome="True"` на интерактивных).
- Правый клик по тайтлбару — системное меню: «Восстановить», «Переместить», «Размер»,
  «Свернуть», «Развернуть», «Закрыть».
- Двойной клик — развернуть/восстановить.
- При ширине окна < 1180 `[TB.Speeds]` скрывается, `[TB.Status]` показывает только точку
  (текст — в тултипе).


|---|---|---|---|
| Заголовок | `LIB.Title` | H1 24/32 | текст зависит от выбранного пункта сайдбара: «Все торренты», «Загружаются», «Раздают», «Завершённые», «Пауза», «Ошибки»; при активном поиске — «Результаты поиска» |

только поиск (до 200), затем заголовок обрезается ellipsis. Сумма правой группы при
1440: 280 + 8 + 32 + 8 + 32 + 8 + 1 + 8 + 148 = 525 DIP, что оставляет заголовку 234.

### 6.1 Поиск

- Placeholder: «Поиск по названию или хешу…», иконка `E721` 16 слева, клиренс `E711` 20
  справа при непустом значении.
- Фокус: `Ctrl+F` (в т.ч. из списка), из любого места страницы.
- Debounce 200 ms; фильтрация — в фоне, UI не блокируется. До 10 000 торрентов — ≤ 60 ms.
- Поиск ищет по: имени (без регистра, `InvariantCultureIgnoreCase`), `InfoHash`
  (полное или первые 8 символов), метке.
- Подсветка совпадения в имени: фон `#3322D3EE`, текст без изменения цвета.
- `Esc` при фокусе в поле: очищает запрос; повторный `Esc` — снимает фокус.
- `Enter`: фокус переходит на первую строку результата.
- Пока идёт ввод — список не мигает скелетоном; показывается прежний результат с
  `Opacity=0.6` до применения нового.
- При пустом результате — состояние «no-results» (§9.3), в тулбаре счётчик «0».

### 6.2 Сортировка

Иконочная кнопка `E8CB` открывает меню (радио-пункты, выбранный — галочка `E73E`).
Текущий порядок виден в тултипе кнопки и в стрелке активной колонки.

| Пункт | Ключ | По умолчанию |
|---|---|---|
| По дате добавления | `AddedAt desc` | ✔ |
| По имени | `Name asc` | |
| По размеру | `Size desc` | |
| По прогрессу | `Progress desc` | |
| По скорости загрузки | `DownloadSpeed desc` | |
| По скорости отдачи | `UploadSpeed desc` | |
| По рейтингу | `Ratio desc` | |
| По оставшемуся времени | `Eta asc` | |

### 7.4 Поведение при большом количестве

| Сценарий | Поведение |
|---|---|
| 1 000+ торрентов | виртуализация, никаких `Effect`, сортировка в фоне |
| 10 000+ | поиск с debounce 200 ms, индикатор «Фильтрация…» 12/16 в шапке колонок, если > 150 ms |
| Частые обновления | один `DispatcherTimer` 500 ms, один проход обновления видимых элементов |
| Смена сортировки | мгновенно применяется к снимку, скролл наверх, выделение сохраняется по `InfoHash` |
| Добавление 50 файлов | строки появляются пакетом, скелетоны не используются |

### 7.5 Bulk-бар выделения

Появляется при выделении ≥ 1, поверх списка: `HorizontalAlignment=Center`,
`VerticalAlignment=Bottom`, отступ снизу 16, высота 48, радиус 12, фон `#1B2130`,
граница 1 px `#364159`, тень E3, padding `12,0`, max-width 720.

```
  Выбрано 3   │  [Пауза]  [Продолжить]  [Метка]  [Удалить]  [Ещё ▾]   ✕
   13 SemiBold    Ghost Small 28 px, иконки 14 слева
```

- Показывается с `TranslateY 12→0` + fade 180 ms, скрывается 120 ms.
- «Ещё ▾»: «Копировать magnet-ссылки», «Переместить данные…», «Приоритет файлов»,
  «Снять выделение».
- «✕» и `Esc` снимают выделение.
- Счётчик: «Выбрано 1», «Выбрано 3», «Выбрано 128» — без склонения слова «торрент»
  (счётчик — отдельный чип, форма слова не требуется).
- При открытом bulk-баре нижняя карточка не перекрывается: список получает
  `Padding="0,0,0,72"`.

Строка: имя «Получение метаданных…», indeterminate-бар 60 % ширины, метаданные

## 11. Сценарии добавления

### 11.1 Magnet из буфера обмена

| Шаг | Действие | Результат | Время |
|---|---|---|---|
| 1 | `Ctrl+V` в окне (фокус не в поле ввода) | модалка открывается, поле заполнено, идёт валидация | ≤ 120 ms |
| 2 | Валидация проходит | кнопка «Добавить» активна, фокус на ней | ≤ 200 ms |
| 3 | `Enter` | кнопка «Добавление…», модалка закрыта | ≤ 150 ms |
| 4 | Движок принял | строка «Получение метаданных…» в списке + тост «Торрент добавлен» | ≤ 500 ms |
| 5 | Метаданные получены | имя, размер, файлы, трекеры обновлены; тост «Метаданные получены» | по сети |

Ошибки: невалидная ссылка — модалка с текстом; ошибка записи — модалка + тост.
`Ctrl+Shift+V` — добавление сразу, без модалки (валидация в фоне, тост с «Отменить»).

### 11.2 Файл .torrent

1. `Ctrl+O` или `[LIB.Add] → Открыть .torrent…` → системный диалог
   (фильтр «Торрент-файлы (*.torrent)|*.torrent», мультивыбор).
2. Выбран 1 файл → модалка, режим «Файл», карточка файла (имя, размер, «Заменить файл»),
   список файлов торрента.
3. Выбрано 2–20 файлов → модалка не открывается: очередь добавляет все, тост
   «Добавлено 5 торрентов» с «Показать».
4. Ошибка одного файла не прерывает очередь; итог — тост
   «Добавлено 4 из 5. Один файл не удалось прочитать» + «Подробнее».

### 11.3 Drag&drop

См. §12. Один файл → добавление без модалки, тост с «Отменить» (10 s).
Несколько → тост «Добавлено N торрентов». Папка → сканируется на `*.torrent`
(рекурсивно, максимум 100 файлов), результат — тост с количеством.

### 11.4 Двойной клик по .torrent в Проводнике (ассоциация файлов)

1. Приложение получает путь через аргументы командной строки / single-instance pipe.
2. Если окно скрыто в трее — показывается и активируется.
3. Файл добавляется сразу, без модалки; тост «Торрент добавлен».
4. Если файл уже добавлен — тост «Торрент уже в библиотеке» + «Показать».

### 11.5 Magnet-ссылка из браузера / командной строки

`ztorrent.exe "magnet:?xt=..."` → поведение как в §11.4. Безопасность: ссылка
не логируется целиком, в журнал попадает только `InfoHash`.

### 11.6 Отмена добавления

- До отправки в движок — «Отмена»/`Esc`, ничего не создаётся.
- После отправки (строка уже в списке) — тост «Торрент добавлен» с «Отменить» (10 s):
  удаляет запись без данных, без диалога.

## 19. Тексты и форматы

### 19.1 Форматы значений

| Величина | Правило | Пример |
|---|---|---|
| Скорость ≥ 1 МБ/с | 1 знак после запятой | «7,8 МБ/с» |
| Скорость < 1 МБ/с | целые КБ/с | «824 КБ/с», «512 Б/с» |
| Скорость 0 | «0 Б/с» | — |
| Нет лимита | «∞» | — |
| Неизвестно (пауза, offline) | «—» | — |
| Размер ≥ 1 ГБ | 1 знак | «24,8 ГБ» |
| Размер < 1 ГБ | 1 знак | «842,1 МБ», «12,4 КБ» |
| Прогресс | целые + неразрывный пробел | «62 %» |
| Рейтинг | 2 знака, при отсутствии отдачи «∞» | «1,42» |
| ETA | «≈ 24 мин», «≈ 2 ч 10 мин», «> 1 сут», «—» при неизвестном | — |
| Дата | «12 окт, 14:05» (месяцы: янв, фев, мар, апр, мая, июн, июл, авг, сен, окт, ноя, дек) | — |
| Относительное время | «только что», «5 мин назад», «2 ч назад», «вчера», «12 окт» | — |
| Количество | неразрывный пробел как разделитель тысяч | «1 248» |
| InfoHash | первые 8 символов + «…», полный — в тултипе и при копировании | «9f2c4a71…» |

Все числа — `ru-RU`: запятая как десятичный разделитель, неразрывный пробел (`U+00A0`)
между числом и единицей. Табличные цифры обязательны, чтобы значения не «прыгали».

| метка | метка | метки | меток |
| минута | минута | минуты | минут |

| `VT-LIM-001` | Неверный лимит | «Введите число от 0 до 1 048 576 КБ/с. 0 — без ограничения.» | — | под полем |
| `VT-PERM-001` | Нет прав на папку | «Папка загрузок недоступна для записи. Выберите другую папку.» | «Изменить…» | настройки |

Правила текстов ошибок: без технического жаргона, без «Error», без кодов в основном
тексте (код — в тултипе/подробностях), всегда есть следующее действие; одно предложение
о причине + одно о действии; обращение на «вы» без местоимения.

## 20. Адаптивность и DPI

### 20.1 Ширина окна

Опорные разрешения (все значения — DIP, при 100 % DPI):

| Разрешение | Сайдбар | Детали | Область списка | Gutter | Карточка | Имя | Строк |
|---|---|---|---|---|---|---|---|
| 1280 × 800 | 232 | 336 | 711 | 20 | 671 | 323 | 7 |
| 1440 × 900 | 248 | 384 | 807 | 24 | 759 | 363 | 9 |
| 1920 × 1080 | 264 | 420 | 1235 | 32 | 1171 | 711 | 11 |

Колонки карточки адаптируются: при ширине < 1360 прогресс 120, скорости 100, зазоры
12/12/12/8; при ≥ 1680 прогресс 180, скорости 140; при 1360–1679 — базовые 140/116.
Остальное забирает колонка имени.

| Диапазон | Сайдбар | Детали | Gutter | Поведение |
|---|---|---|---|---|
| ≥ 1680 | 264 | 420 | 32 | всё видимо |
| 1360–1679 | 248 | 384 | 24 | базовый макет |
| 1180–1359 | 232 | 336 | 20 | поиск сжимается до 240 |
| 1024–1179 | 72 (rail) | 320 (оверлей) | 16 | детали — оверлей поверх списка, закрывается `Esc`/кликом вне |

В rail-режиме панель деталей не отнимает ширину, а накрывает список справа,
с тенью E3 и скримом 40 % только над списком.

### 20.2 Высота окна и число строк

| Высота | Доступно под список | Строк без строки фильтров | Со строкой фильтров (−36) |
|---|---|---|---|
| 800 | 664 | 7 | 7 |
| 900 | 764 | 9 | 8 |
| 1080 | 944 | 11 | 10 |

Формула: `строк = floor((H_list − 8) / 84)`, где `H_list = H − 40 − 64 − 32 − [36]`,
84 = 76 + 8, а 8 — верхний отступ. Проверка для 900: `(764 − 8) / 84 = 9` — ровно 9 строк
(684 + 64 + 16 = 764). Для 800: `(664 − 8) / 84 = 7,8` → 7 строк (596 px) + 68 px остатка.
Минимальная высота — `min(640, WorkArea.Height)`; при нехватке места список скроллится.

### 20.3 DPI

Все размеры в DIP, поэтому масштабирование системное. Проверять на каждом значении:

| DPI | Масштаб | Что проверить |
|---|---|---|
| 100 % | 1.0 | базовая линия, `TextFormattingMode=Display` |
| 125 % | 1.25 | границы 1 px не «пропадают»; иконки 14/16 целые; ellipsis не режет слова на 62 % ширины |
| 150 % | 1.5 | прогресс 6 → 9 px физических; кольцо фокуса 2 → 3 px; `TextFormattingMode=Ideal` |
| 175 % | 1.75 | минимальное окно 1024 × 640 не влезает в 1920 × 1080 (1097 × 617 DIP) — проверить rail + оверлей деталей |
| 200 % | 2.0 | доступно 960 × 540 DIP: стартовать в rail-режиме, детали — оверлей, высота окна клампится по `WorkArea` |

Правила:
- `UseLayoutRounding=True`, `SnapsToDevicePixels=True` на корне и контейнерах.
- Никаких дробных отступов и размеров шрифта.
- Иконки — целые размеры из шкалы (12/14/16/20/24/32/48), не масштабируются трансформом.
- Начальный размер окна: `min(1440, WorkArea.Width − 80) × min(900, WorkArea.Height − 80)`,
  но не меньше минимального; положение — по центру.
- При смене DPI во время работы пересчитывается только layout; анимации не перезапускаются.
- Скриншот-тест на 125 %, 150 %, 200 % обязателен для карточки, деталей и модалки.

## 21. Обновление данных и производительность

```
MonoTorrent events ──► ConcurrentQueue (без блокировок)
                          │
                          ▼
              агрегатор каждые 500 ms          ← не чаще 2 Гц
                          │
                          ▼
        ImmutableSnapshot (торренты, пиры, трекеры)
                          │
                          ▼
     UI: один Dispatcher-проход, обновление видимых строк + шапки
```

| Правило | Значение |
|---|---|
| Частота обновления UI | 2 Гц (500 ms), при простое — 1 Гц |
| Обновление строки | только если изменилось отображаемое значение (сравнение хеша) |
| Сортировка/фильтрация | фоновая задача, `CancellationToken`, debounce 200 ms для поиска |
| Смена сортировки | применяется к снимку, без обращения к движку |
| График скорости | 60 точек, кольцевой буфер, перестроение `StreamGeometry` ≤ 1 Гц |
| Анимации | только `Opacity` и `RenderTransform`; см. design-system §8 |
| Список | `VirtualizingStackPanel` + `Recycling`, фиксированная высота строки |
| Блокировки | никаких `.Result`/`.Wait()` в UI-потоке; все вызовы движка — async |
| Память | снимок переиспользуется, строки-ViewModel не пересоздаются при обновлении |
| Цель | 10 000 торрентов: скролл 60 fps, обновление тика ≤ 8 ms |

## 22. Приёмочные критерии (UX)

1. Окно запускается 1440 × 900 по центру, все зоны совпадают с §3.2 с точностью ±1 DIP.
2. Каждая карточка при 1440 показывает 6 параметров без обрезки: имя, размер, скорость ↓,
   скорость ↑, процент, ETA; имя обрезается только при переполнении.
3. Выделение, hover и фокус различимы при 100 % и 200 % DPI; фокус виден только с клавиатуры.
4. Все действия доступны без мыши; `Tab` не попадает в декоративные элементы.
5. Пустая библиотека, поиск без результатов, ошибка сессии, offline — каждое состояние
   имеет заголовок, объяснение и действие.
6. Добавление magnet и .torrent проходит за ≤ 3 действия; невалидный ввод не отправляется.
7. Ошибки объясняют причину и следующее действие; коды ошибок не видны в основном тексте.
8. Удаление с данными всегда требует диалога; «Отмена» в фокусе по умолчанию.
9. Тосты не перекрывают кнопки модалки и не воруют фокус; ошибки не исчезают сами.
10. При 10 000 торрентов скролл плавный, поиск отвечает ≤ 100 ms, память не растёт.
11. Ни одна анимация не длится дольше 360 ms (кроме shimmer/indeterminate/скелетона).
12. При «Выключенных анимациях» интерфейс полностью функционален и не «дёргается».
13. Контраст всех текстовых пар ≥ 4,5:1 (кроме disabled), проверено по design-system §9.1.
14. Статус читается без цвета: у каждой строки есть иконка, у чипа — текст.
15. Русские тексты соответствуют §19, плюрализация верна для 1/2/5/21.
16. Числа не «прыгают» при обновлении (tabular figures, фиксированные колонки).
17. При 200 % DPI окно пригодно к работе: rail-сайдбар, детали-оверлей, нет обрезанных
    контролов.
18. `Esc` закрывает верхний слой (модалка → фильтр → поиск → выделение) по приоритету.
19. Трей: закрытие сворачивает, двойной клик возвращает, «Выход» останавливает движок
    корректно.
20. Скринридер читает имя, состояние и прогресс каждой строки; иконочные кнопки озвучены.
