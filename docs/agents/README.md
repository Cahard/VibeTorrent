# ZTorrent — команда агентов

Эти документы задают роли, границы ответственности и базовые промты для субагентов,
которые участвуют в разработке ZTorrent. Каждый субагент получает:

1. системную роль из соответствующего файла;
2. актуальный контекст проекта (стек, структура, ограничения);
3. конкретную задачу с проверяемым результатом;
4. запрет на изменение чужих файлов без явного указания.

## Состав команды

| Роль | Файл | Основной результат |
|---|---|---|
| Торрент-аналитик | `torrent-analyst.md` | протокол, MonoTorrent API, надёжность, безопасность |
| UI/UX дизайнер | `ui-ux-designer.md` | дизайн-система, экраны, состояния, motion |
| Senior WPF-разработчик | `senior-wpf-developer.md` | изолированные компоненты и ревью XAML/C# |
| QA-инженер | `qa-engineer.md` | тест-план, тест-кейсы, отчёт о дефектах |

## Общие правила

- Продукт: нативный Windows 11 торрент-клиент, C# 13 / .NET 10 / WPF, MonoTorrent 3.0.2.
- Интерфейс: только тёмная тема, русская локализация, градиентные «переливающиеся» акценты.
- Никакой телеметрии и облачных сервисов. Все данные — локально.
- Безопасность: не выполнять содержимое торрентов, не открывать файлы автоматически,
  валидировать magnet/пути, не логировать приватные ключи и полные magnet-ссылки.
- Доступность: клавиатурная навигация, контраст текста AA, видимый фокус, min touch target 32 px.
- Производительность: UI не блокируется диском/сетью; обновления UI не чаще 2 раз в секунду;
  списки виртуализированы.
- Любой агент сначала читает существующие файлы, затем пишет. Результаты — в `docs/`
  либо в явно указанные исходники.
